# 《红色警戒：心灵风暴》游戏规则文档

> 本作是《命令与征服：红色警戒 2 - 尤里的复仇》遭遇战玩法的**非官方致敬复刻版**。
> 所有美术与音效均为程序化生成的原创素材，不含任何 EA 原版资源；单位与建筑的定位、造价、
> 血量、射程等数值参考公开资料做同量级还原，并在可玩性上做了少量平衡调整。
> 本文档与 `game/data.py` 中的实际数值一一对应，是当前版本的唯一数值事实来源。

## 3. 建造与科技

### 3.1 建造规则

- 所有建筑必须有**建造厂（CY）**才能建造；建造厂本身可被重建。
- 建筑必须先在生产队列中完成，再手动放置；放置位置必须距己方任意建筑中心 **< 9 格**，
  且占地格全部可建造。
- 单位在对应生产建筑（兵营/战车工厂）中训练，训练完成自动出现在建筑出口并前往集结点。
- 生产队列分三类：建筑 / 步兵 / 载具，各自独立并行；下单即扣款，取消全额退款。
- 建造时间 = 造价 × 系数（单位 0.013 秒/资金，建筑 0.0135 秒/资金，单位最低 3 秒、
  建筑最低 5 秒）；落地后有 1.4 秒施工动画，期间血量从 15% 线性涨到 100%。
- 起始基地直接免费建成并满血（建造厂、电厂、精炼厂、战车工厂、兵营各一座 + 采矿车、
  坦克与 3 名步兵）。

### 3.2 电力

- 电厂提供 **+100** 电力；建筑按 `power` 字段消耗电力（精炼厂 -35、战车工厂 -35、
  兵营 -15、雷达 -25、防御塔 -10 ~ -30、超级武器 -80）。
- 电力不足（消耗 > 产出）时：
  - 生产速度 × 0.6
  - 防御建筑射速 × 1.5（即冷却时间 × 1.5）
  - 超级武器充能速度 × 0.55
- 起始基地电力为 100 - 85 = **+15**，扩建雷达/防御/超级武器需要补电厂。

### 3.3 科技树

```
建造厂
 ├─ 电厂 ────────────── 电力
 ├─ 精炼厂 ──────────── 采矿车（并附赠一辆）
 ├─ 兵营 ────────────── 步兵
 ├─ 战车工厂 ────────── 载具 / 采矿车
 └─ 雷达站（二级科技）
      ├─ 二级载具（光棱/夜鹰、天启/V3/基洛夫、磁电/控制车/飞碟/复制人）
      ├─ 高级防御（光棱塔 / 防空炮 / 加特林炮）
      └─ 超级武器（天气控制器 / 核弹发射井 / 心灵控制器）
```

规则：所有 `tier >= 2` 的内容额外要求雷达站（雷达站自身除外）。

## 4. 战斗系统

### 4.1 伤害公式

```
最终伤害 = 武器基础伤害 × 弹头对该装甲的倍率 × 老兵伤害倍率
```

- 老兵倍率：0 级 1.00，1 级 1.20，2 级 1.45。
- 击杀 3 个单位升 1 级，再击杀 8 个升 2 级；升级时最大生命 ×1.15 / ×1.30，并回复 20% 生命。
- 溅射伤害：以落点为圆心，中心 100% 递减到边缘 35%（`0.35 + 0.65 × 距离比例`）。
- 溅射对友军只造成 35% 伤害。
- 弹头倍率为 0 时完全免疫（例如磁力武器对步兵/建筑无效）。

### 4.3 特殊机制

- **心灵控制**：控制者存在期间目标永久为己方作战；控制者死亡或控制数量超限时目标解放。
- **工程师**：进入敌方建筑即占领，建筑满血归己方，工程师消耗。
- **自爆单位**：恐怖机器人等冲向目标后引爆，造成范围爆破伤害。
- **狂暴**：神经突击车死亡时释放毒气，使周围敌军短时间无差别攻击。
- **防空**：`can_air = False` 的武器无法攻击空中单位；飞行单位无视地形。

## 9. AI 行为

AI 与玩家使用完全相同的经济与生产规则（仅按难度有收入/速度加成），决策周期
0.35~1.2 秒，行为如下：

1. **经济**：优先补电厂与精炼厂；矿车目标数 = 2 + 精炼厂数；缺矿车且资金不足时暂停造兵攒钱；
   矿车全灭时优先补精炼厂（附带赠车）。
2. **建筑**：按 电厂 → 精炼厂 → 兵营 → 战车工厂 → 雷达 → 防御塔 ×2~3 → 超级武器的顺序推进。
3. **防守**：基地 9 格内出现敌军时，空闲部队自动回防攻击威胁目标。
4. **进攻**：部队数量达到阈值后集结，保留 2 个单位守家，其余以“攻击移动”扑向最近的敌方建筑；
   每波间隔按难度为 55 / 40 / 30 秒。
5. **兵力上限**：常备部队上限为 10 / 14 / 18（简单/普通/困难），达到后停止暴兵。
6. **超级武器**：自动寻找敌军最密集处释放；基地 12 格内无敌人且超级武器未建成时，
   AI 会暂停造兵优先攒钱，确保中期能造出超级武器。

| 难度 | 收入倍率 | 生产速度 | 进攻兵力阈值 | 进攻间隔 |

| 简单 | 0.75 | 0.85 | 4（实际出兵 4+2） | 55 秒 |

## 11. 迷雾与视野

- 每格分“可见 / 已探索”两级；玩家只能看到己方单位与建筑视野内的实时敌军。
- 敌方建筑在已探索区域显示（灰色残影），敌方单位只有进入视野才显示。
- 迷雾每 0.22 秒刷新一次；AI 不受迷雾限制。
